# EcoSpace Sea

Інтерактивний 3D-прототип глемпінгу в Толокуні для Nevercodes. У сцені є берег Київського водосховища, вісім житлових куполів, ресторан, басейн, SPA та пірс.

## Запуск

Потрібен Node.js 20.19+ або 22.12+.

```sh
npm ci
npm run dev
npm run build
```

Відкрийте URL, який покаже Vite. Скрол, навігація та маркери на сцені перемикають камеру. Натисніть «Сутінки», щоб змінити освітлення. Бронювання веде на чинний сайт EcoSpace Sea.

## Геометрія та джерела

- [Дослідження й референси](https://app.notion.com/p/422f5a8f9eb081ef92f4ccf9262ceaaf?pvs=204)
- [Аерофото та проєкт ECOPOD](https://ecopod.ua/projects/ecospace)
- [Габарити E7 та E8](https://ecopod.ua/glampingdomes) · [Event 13](https://ecopod.ua/event-domes)
- [Офіційні галереї EcoSpace Sea](https://sea.ecospace.ua/kypolu)

`src/site-geometry.json` містить орієнтири у WGS84 та їхні локальні координати в метрах від центру ресторанного купола. Сцена використовує X = схід, Y = висота, Z = мінус північ. Центри куполів та берег взято із дослідження. Терраси, висоти берегової бровки, інтер’єрні силуети, під’їзд і декор наближені. Положення пірса відновлено за історичним аерофото. Назви окремих слотів і розташування SPA потрібно звірити з актуальним генпланом. Геометрія, текстури та освітлення створені процедурно.

## Структура

- `src/site.js` — імпорт геометрії та налаштування камер.
- `src/landscape.js` — берег, рельєф, дерева, вода та небо.
- `src/architecture.js` — куполи, настили, басейн, сауна та пірс.
- `src/world.js` — рендеринг, світло, анімація та проєкція маркерів.
